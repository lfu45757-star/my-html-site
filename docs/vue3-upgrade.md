# Vue 3 个人网站升级验收

日期：2026-11-09（Asia/Shanghai）

## 实现范围

保留四个静态页面及已有的三个项目，不引入后端、路由器或运行时外部服务。使用本地 Vue 3.5.45 生产运行库，在现有 HTML 上渐进增强。

- 首页：个人介绍、代码插画、技术栈、项目、真实提交日期对应的学习时间线。
- 项目页：类别与关键词组合筛选、结果数量、空结果重置、详情弹窗及 GitHub 外链。
- 联系页：必填与邮箱校验、空格内容校验、字数统计、安全文本预览、编码后的邮件草稿链接、复制与失败提示。
- 全站：响应式布局、深浅主题、移动菜单、跳到正文、键盘焦点、返回顶部、减少动态效果偏好、404 返回路径。

## 检查方式

```powershell
npm test
npm run test:browser
npm run build
```

机器摘要见 `checks/vue3-checks.json`。Playwright 使用本机已安装的 Edge / Chromium 内核，12 组布局检查覆盖四个页面 × 360 / 768 / 1440 px。

本次最终结果：**10 项静态检查通过、26 项浏览器测试通过、静态导出成功**。生产依赖审计未报告已知漏洞；这不等于对整个站点做出了安全保证。

交互覆盖：组合搜索、空结果、详情焦点与 Escape、主题跨页面持久化、移动导航与断点焦点、邮件内容转义与编码、未发送的明确说明、存储禁用、Vue 加载失败、无 JavaScript、复制权限被拒、空格表单、返回顶部和图片格式。

检查不向真实邮箱发信，不点击外站的写入操作。预览服务器的私有路径访问返回 404。

## 明确边界

- 没有在线发信服务或数据后台。生成邮件不等于发送邮件。
- 没有启用或验收公网部署；GitHub 同步只代表源码已推送。
- 未重跑 Lighthouse，不复用历史分数声称新版得分。
- 本次浏览器检查不是 Safari、Firefox、真实设备或生产环境性能测试。
- 404 的 GitHub Pages 基址按当前仓库名配置；更名或非根目录自定义部署需调整。
- 旧版文件备份保存在被 Git 忽略的 `.local-backups/`，不推送到仓库。可通过 Git 的 `0b09d33` 提交查看本次修改前的版本；如需回退已共享的更新，使用 `git revert`，不要强制重写远程历史。
